MaiAI CRM API

Tài liệu đầy đủ các endpoint REST API của hệ thống quản lý salon MaiAI CRM.
Mỗi section mô tả tính năng sử dụng API đó và chi tiết request/response.

Base URL http://localhost:3001/api

Xác thực
Cách gửi token trong mỗi request

Hầu hết các API yêu cầu JWT token trong header. Gọi POST /api/auth/login để lấy token, sau đó gửi kèm mỗi request:

Header
KeyValueBắt buộc
AuthorizationBearer <token>✓ Có
Content-Typeapplication/json✓ Với POST/PUT/PATCH

Các route admin (/api/admin/*) dùng header X-Admin-Key thay cho JWT.

🔐
